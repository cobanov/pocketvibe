Vibe-coded games, in your pocket.

PocketVibe is a launcher and game store for ROCKNIX and Android handhelds, full of three.js games made with AI coding tools. Pick one and play it with the handheld's buttons.

Every game in the store runs on this page. Pick one and it starts on the handheld.

    Put it on your handheld

    On ROCKNIX

    1. 1

      Download PocketVibe.zip

      The handheld needs Wi-Fi for the store.

    2. 2

      Unzip it into roms/ports

      On the handheld's SD card, from your computer or over the handheld's network share.

    3. 3

      Restart, then open Ports and PocketVibe

      The first start downloads the game engine, about 150 MB, in about two minutes over Wi-Fi. After that PocketVibe opens in seconds and keeps itself up to date.

    In a game, hold Start and Select to go back to PocketVibe.

    On Android

    1. 1

      Download PocketVibe.apk

      On the handheld. It needs Android 10 or newer.

    2. 2

      Open it and tap Install

      When Android asks, allow your browser or file manager to install apps.

    3. 3

      Start PocketVibe from the app list

      Made for handhelds with buttons, such as the Retroid Pocket or the Anbernic RG Rotate. A new version installs over the old one.

    In a game, hold Start and Select, or press Back, to go back to PocketVibe.

    Make your own game

    Start from a project that already knows the handheld.

    npm create pocketvibe@latest my-game
cd my-game
npm install
npm run dev

    Describe your game to your AI coding tool. The project's AGENTS.md tells it the screen size, the buttons and the performance budget measured on the handheld, so the game runs at 60 fps there too. Your browser shows it at the handheld's 720 by 480, with its buttons on your keyboard.

    When it plays well, publish it to the store. You sign in with GitHub, and a new game appears once it is reviewed.

    npx pocketvibe publish
