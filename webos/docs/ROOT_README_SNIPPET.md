## LG webOS TV (community port)

This fork also runs PocketVibe on **LG webOS TVs**, with the Magic Remote or a USB/Bluetooth gamepad.
Install the `.ipk` from [Releases](../../releases) or build it with `./webos/build.sh`. See [webos/README.md](webos/README.md).
