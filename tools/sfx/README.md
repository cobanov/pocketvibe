<h1 align="center">PocketVibe launcher sounds</h1>

<p align="center">
  <strong>The launcher's 16 UI sound effects, generated by code.</strong><br>
  Procedurally synthesised for a PSP / PS Vita / 3DS style menu; nothing recorded, nothing to license.
</p>

`make_sfx.py` writes every sound to `app/pocketvibe/launcher/sounds/` as a 48 kHz, 16-bit stereo
WAV. Those WAVs are what the launcher ships and plays (`app/pocketvibe/launcher/audio.js`).
`manifest.json` lists each sound's trigger, length and peak level; it is written by hand.

- **Change a sound by editing its function and regenerating.** Never edit the WAV files by hand.
- **All tonal sounds are in D major**, so sounds that overlap stay consonant.
- **The levels are intentional.** Frequent sounds are quiet (`nav_move` -15 dBFS, `nav_scroll` -20,
  `key_type` -18), one-shots are loud (`launch_game` -3, `boot` -2). Do not loudness-normalise them;
  the launcher has one shared effects volume instead.
- **WAV, not OGG or MP3.** The handheld's WebKit decodes through GStreamer: a WAV decodes in about
  60 ms, the same sound as OGG in about 1.5 s, so sixteen OGGs would hold up startup by ~24 s. MP3
  adds encoder padding, which delays a sound.

## Regenerate

```sh
uv run --no-project --with numpy --with scipy --with soundfile python tools/sfx/make_sfx.py
```

Or `pip install numpy scipy soundfile` and `python3 tools/sfx/make_sfx.py`. The generator is seeded,
so an unchanged script writes the same files byte for byte.

## The menu music

`app/pocketvibe/launcher/music/menu_theme_full.ogg` is not made here: it was generated with
ACE-Step 1.5 XL-SFT (nu-jazz, 84 BPM, C minor, instrumental), 48 kHz stereo, mastered to -21 LUFS
so it sits under the UI sounds. A 30.33 s intro plays once, then 30.33 s to the end loops; the
loop points are in `audio.js`. It ships as OGG because one 2.1 MB file decodes in about 5 s in the
background, while the WAV would be 19 MB.

## The games' sounds

The games in `games/` get their sound from here too, starting with the five PocketVibe ships with
(Brick Breaker, Turbo Circuit, Jet Rush, Tower Stack, Road Hopper). Pulse Dash and Pole Star
synthesise their own music in the game, in time with play.

- `sound.js` is the games' sound module: each game has an unchanged copy in `src/sound.js`. It loads
  the effects and the music, plays them through Web Audio, saves the player's Sound and Music
  choices, and starts audio on the handheld: WebKit wants a key press first and gamepad buttons do
  not count, so the game asks pocketvibed (`POST /__pocketvibe__/unlock-audio` on the game's own
  port) to tap the virtual key the launcher also uses.
- `synth.py` holds the building blocks, `games/<id>.py` each game's effects. A recipe writes 48 kHz
  mono WAVs to `games/<id>/public/sfx/`, the same files byte for byte on every run:

  ```sh
  uv run --no-project --with numpy --with scipy --with soundfile python tools/sfx/games/<id>.py
  ```

- The music (`games/<id>/public/music/theme.ogg`) was generated with ACE-Step 1.5 XL-SFT by
  `game_music_acestep.py`, which holds the prompts (three takes per game, 90 s each), and cut into
  a seamless loop by `make_music_loop.py`: whole bars from after the intro, the end crossfaded into
  the start, -16 LUFS (sound.js plays it at 0.55, under the effects), Ogg Vorbis.
